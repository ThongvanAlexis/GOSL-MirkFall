Quand `MirkRenderer.paint(canvas, size, context)` est appelé par `FogLayer._FogPainter` :
- le canvas est déjà `save()` + `translate(-canvasOffset)` (repère identité = repère du `CircleLayer` puck) ;
- le canvas est déjà `clipPath(rect(size) − ∪ disques)` — peindre `Offset.zero & size` suffit, les trous sont garantis ;

- `context.pixelOrigin` est déjà corrigé plateforme (FOG-23), `context.sdfRect` aussi (FOG-21) ;
- `context.zoomScale == pow(2, zoom − 13)`.

Helper de test cible (`test/infrastructure/mirk/_render_helpers.dart`) :
```dart
Future<Uint8List> renderToBytes(MirkRenderer renderer, {required MirkPaintContext context, Size size = kTestCanvasSize, bool applyClip = true});
Picture renderToPicture(MirkRenderer renderer, {required MirkPaintContext context, Size size = kTestCanvasSize, bool applyClip = true});
// applyClip → canvas.save(); canvas.clipPath(buildFogClipPath(size: size, discs: context.discs, projectToScreen: context.projectToScreen, metersToPixels: context.metersToPixels)); renderer.update(context.sessionElapsed); renderer.paint(canvas, size, context); canvas.restore();
```
Noise CPU ancré (heavenly, et tout futur renderer CPU) :
```dart
// pour chaque pixel (sx, sy) de la texture / du dessin :
final double worldX = sx + context.pixelOrigin.x;   // pixelOrigin.y déjà signé plateforme — sur Android le noise CPU doit utiliser la valeur NON flippée :
final double worldY = sy + rawPixelOriginY;         // → exposer dans le contexte ? NON (extension unique). Utiliser `context.pixelOrigin.y.abs()` est FAUX (perte de signe réel).
```
→ Règle : le sign-flip FOG-23 compense un bug de codegen GPU ; le CPU n'en souffre pas. Le renderer CPU reconstruit la valeur brute : `rawY = isAndroidCorrected ? -context.pixelOrigin.y : context.pixelOrigin.y` où `isAndroidCorrected = context.sdfRect == (0.0, 1.0, 1.0, -1.0)` (le `sdfRect` Android est le marqueur fiable de la correction appliquée — documenter ce couplage dans une fonction nommée `rawPixelOriginOf(MirkPaintContext)` dans `fog_platform_corrections.dart`, testée).
