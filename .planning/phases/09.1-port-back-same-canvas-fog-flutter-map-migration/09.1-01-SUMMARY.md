## Decisions Made

- **Coexistence strategy confirmed, fallback unused.** The resolver accepted `maplibre_gl 0.25.0` + the flutter_map stack in one pass ("Changed 18 dependencies"), so the stub-`MapLibreMapViewWidget` fallback described in Task 1 was never triggered. `maplibre_map_view.dart` is untouched (one docstring line renamed).
- **Unified diag rollup constant.** The POC's four `*LogRollupSeconds` are all 1 s and exist only to be joinable on the same `epochSecond`; a single `kMirkFogDiagRollupSeconds` expresses that intent directly and matches the name 09.1-05 already uses.
- **Overlay placement px not ported.** `kPocFrameDeltaProbeOverlayTopPx` / `RightPx` are HUD layout for `frame_delta_probe_overlay.dart`, which no 09.1 plan ports (09.1-04 ports the three loggers only). The thresholds and buffers the loggers/probe consume are ported. If 09.1-07 decides to port the overlay, the two px values can be hoisted then.
- **`kMirkFogDiagSmoothCoordinateMaxDelta` ported now.** 09.1-04 says "port it here if 09.1-01 did not"; doing it here keeps `constants.dart` single-owner in Wave 2/3.
- **Docstrings in English** for the new block, consistent with the rest of `constants.dart` (the plan snippet was French; content preserved).
