## Decisions Made

- **Freezed vs manual class:** Freezed kept. freezed 3.2.5 handles `({double x, double y})`, `(double, double, double, double)` and function-typed fields; generated `==` is structural for records and identity for closures, which is exactly the documented semantics. No `copyWith` friction either.
- **Where the overlay builds its context:** in `_MirkPainter.paint(canvas, size)`, not in `build()` — `projectToScreen` / `metersToPixels` need the real canvas size. Neutral values are named file-level constants (no magic numbers). Presentation now imports `lib/infrastructure/mirk/mirk_projection.dart` (precedent: `map_screen.dart` imports infrastructure); it disappears with the overlay in 09.1-07.
- **`uTime` precision:** shader path uses `sessionElapsed.inMicroseconds / Duration.microsecondsPerSecond` (plan) while the wisp `dt` keeps the millisecond form; the seed jitter `0.137` became `_kSeedTimeJitter` with its rationale.
- **`FogShaderTunableKey`** (string constants + `all` in slot order) instead of bare string literals at the 2 × 20 call sites; a missing key throws `ArgumentError` (programming error, propagates).
- **Tunables map built per paint** rather than cached — the in-app tuner mutates `MirkRuntimeTunables.instance` between frames; the test "a tunable changed between two paints reaches the seam" locks this.
- **Docstrings in English** for new code, consistent with the surrounding files (plan snippets were French; content preserved; the `// Provisoire 09.1-03 → supprimé …` marker requested by the plan is kept verbatim in French).
