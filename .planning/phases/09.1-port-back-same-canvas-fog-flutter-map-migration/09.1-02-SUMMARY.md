## Decisions Made

- **`onMapReady` strategy.** flutter_map 7.0.2 calls `MapOptions.onMapReady` from `WidgetsBinding.addPostFrameCallback` (`widget.dart:63`), i.e. outside any build phase, so `MapScreen._onMapReady` publishes the adapter and calls `openForSession` directly. The `_publishMapViewAfterFrame` indirection and its maplibre #717 docstring are gone; the `deactivate()` + microtask `set(null)` path is untouched.
- **Before-ready semantics.** `queryViewport()` → `initialCamera`; `moveCameraTo()` → ignored at FINE; `queryViewportBounds()` → `StateError` (the `MapViewport` provider already catches and retries). After `dispose()`: zeros / 0-bbox, as in Phase 07.
- **`_ArchiveTileProvider`.** Found by the widget test: `dispose()` closed the archive while `VectorTileLayer` still had reads in flight → `StateError: withResource() may not be called on a closed Pool` reported (non-silent) through the image resource service — on a real device that is a SHOUT on every `/map` pop. The wrapper counts in-flight `provide()` calls, answers post-close reads with a 404 `ProviderException` (rendered as an empty tile, unreported by `VectorTileLoadingCache`), and closes when idle. Justified wrapper: lifecycle logic, not delegation.
- **Cancellation noise.** vector_map_tiles reports cancelled raster jobs with `silent: true` and lets some render-job cancellations escape its executor as uncaught async errors (debug `QueueExecutor` / release `PoolExecutor` alike). `main.dart` now (a) logs `silent` FlutterError reports at FINE and (b) downgrades `CancellationException` (matched by type name — `executor_lib` is transitive, see deferred-items #3) in the FlutterError / PlatformDispatcher / zone sinks.
- **Widget test shape.** `flutter_test` asserts that its own handler records zone-escaped errors, so they cannot be swallowed in `onError` (the POC helper only covered the silent path). Final shape: silent-only filter + `settleTiles` (600 ms of real time + frames) before every unmount / swap + a single-exception drain fallback; 320×320 viewport. Stable across 3 consecutive runs (9/9, ~13 s).
- **Docstrings in English** for new code, consistent with the surrounding files (plan snippets were French; content preserved).
