## Phase Boundary

### Pourquoi cette phase existe

Le fog de MirkFall ne suit pas la caméra. `MirkOverlay` est un `CustomPaint` empilé au-dessus de la platform view MapLibre : deux pipelines de rendu (GL natif vs Canvas Flutter), donc 1 à 3 frames de retard visibles à chaque pan / zoom. BUG-014 a brûlé 6 itérations (sdfRect remapping, image source MapLibre, transform Canvas affine) sans résultat, toutes revertées. Le tracker `docs/phase09-bug-tracking/BUG-014-sdf-rect-offset-axes.md` reste ouvert.

Le POC `mirk-poc-debug` (2026-04-30 → 2026-05-31) a testé l'hypothèse "same-canvas" : remplacer `maplibre_gl` par `flutter_map` + `vector_map_tiles` pour que les tuiles ET le fog soient peints dans le même Canvas Flutter, même frame, même transform. Verdict formel dans `VERDICT.md` : **CONFIRMED-AFTER-FIX, PORT BACK**. Validé iPhone 17 Pro (cible primaire, 100 % résolu pan + zoom + combiné, médiane 1.2 ms/frame) et Pixel 4a (Adreno 618, médiane 25.6 ms ≈ 39 fps, outliers p95 dus au device). `PORTBACK.md` est le playbook de migration : liste fichier-par-fichier, ABI shader 42 slots, 10 invariants, ordre des 13 correctifs, 11 réserves héritées.

Cette phase porte ce résultat dans MirkFall. Ce n'est pas un patch du fog : c'est un changement de moteur de carte, avec le fog qui devient un enfant du widget carte.

### Dans le scope Phase 09.1

1. **Swap du moteur de carte.** Retirer `maplibre_gl 0.25.0`. Ajouter, pinnés aux versions validées par le POC : `flutter_map 7.0.2`, `vector_map_tiles 8.0.0`, `vector_map_tiles_pmtiles 1.5.0`, `vector_tile_renderer 5.2.0`, `pmtiles 1.2.0`, `latlong2 0.9.1`. Audit `DEPENDENCIES.md` obligatoire (l'audit du POC daté 2026-05-05 est réutilisable comme base, à re-dater et à compléter pour les transitives). Licences toutes BSD / MIT / Apache, conformes GOSL.
2. **Nouvelle implémentation de `MapView`.** `lib/infrastructure/map/maplibre_map_view.dart` (595 lignes, seul consommateur maplibre_gl) est remplacé par un adapter `flutter_map` équivalent + son widget. Le seam domaine `lib/domain/map/map_view.dart` est conservé mais nettoyé : `addFogImageSource` / `updateFogImageSource` / `removeFogImageSource` sont des vestiges de l'itération 5 de BUG-014 et disparaissent ; `markVisited` à supprimer si aucun appelant.
3. **Style de carte.** MirkFall a `assets/maps/style.json` (style Mapbox GL, 2 thèmes `MapThemeStandard` / `MapThemeRpgParchment` via `StyleRewriter`). `vector_tile_renderer` lit ce format via `ThemeReader` ; le POC utilisait le thème par défaut `ProtomapsThemes.lightV3()` (caveat #4 du VERDICT). Il faut brancher le style MirkFall et vérifier la compatibilité de ses expressions avec `vector_tile_renderer 5.2.0`. Les glyphs PBF ne servent plus (texte rendu par les fonts Flutter) : statuer sur `assets/maps/glyphs` et `sprites`.
4. **Source PMTiles.** `PmtilesSource` retourne aujourd'hui une URI `pmtiles://file://…` pour MapLibre. Avec `PmTilesVectorTileProvider.fromSource(path)` on lit le fichier directement : `PmtilesSource` retourne un chemin absolu. Le pipeline monde bundlé + téléchargement par pays + `CountryResolver` + hot-swap pays est inchangé côté domaine ; côté widget le hot-swap recrée le provider / `VectorTileLayer`.
5. **Fog same-canvas.** `lib/presentation/widgets/mirk_overlay.dart` (sibling de la platform view dans un `Stack`, `RepaintBoundary`, `IgnorePointer`) est remplacé par un `FogLayer` enfant direct de `FlutterMap`, placé entre `VectorTileLayer` et la couche blue dot. Porter le fix bundle complet du POC : FOG-07 (un seul `MapCamera.of(context)` par build), FOG-12 (un seul `canvas.getTransform()` par paint), FOG-13 (`canvas.translate(-canvasOffset)` symétrique), FOG-17/18 (`uPixelOrigin` forwardé sans modulo), FOG-19 (`uZoomScale` slot 41, noise ancré lat/lng au zoom), FOG-23 (sign-flip `pixelOrigin.y` sur Android, sans quoi stripes horizontales).
6. **Persistance des disques.** Le POC stocke les disques en mémoire (`RevealDiscRepository`). MirkFall a déjà `DriftRevealedDiscStore` (schéma v6, BUG-010) et `RevealStreamingController`. Le `FogLayer` lit les disques via le provider Riverpod existant. Le cache SDF du POC (`SdfCache` + `RevealedSdfBuilder`) remplace la version MirkFall après diff (les deux descendent du même donor).
7. **Wisps en coordonnées monde.** `WispParticle` MirkFall stocke `Offset position` / `Offset velocity` en pixels écran : c'est le piège BUG-014 (dérive au zoom). Remplacer par la version POC (`LatLng position` + `Offset velocityMetersPerSecond`), projection écran dérivée à chaque paint, spawn sur émergence de disque, rendu dans `_FogPainter._renderWisps` après le `drawRect`, avant le `restore`. Firewall : le système de wisps ne touche jamais le `SdfCache`.
8. **Gates CI et tests.** `tool/check_avoid_maplibre_leak.dart` devient un gate `flutter_map` / `latlong2` leak avec périmètre autorisé explicite (voir décisions). `check_avoid_remote_pmtiles` et `check_style_no_external_url` restent. Le test keystone `fog_layer_camera_snapshot_test.dart` du POC devient un gate de régression nommé. Adapter `integration_test/airplane_mode_test.dart`, `map_end_to_end_test.dart`, `test/application/controllers/map_camera_controller_test.dart`. Supprimer les tests de `MirkOverlay` (4 fichiers + `map_screen_repaint_boundary_test.dart`) et `_harness.dart` ajusté.
9. **UAT device.** Checkpoint humain final : marche iPhone (cible primaire, sideload SideStore) + APK Pixel 4a. Critère : zéro déplacement visible du fog pendant pan, zoom, et gestes combinés ; aucune stripe sur Android ; fog conservé après redémarrage de l'app (disques persistés).
10. **Clôture documentaire.** BUG-014 fermé dans `docs/phase09-bug-tracking/` avec référence à cette phase ; `PROJECT.md` Key Decisions enregistre le changement de moteur ; `docs/POC-flutter-map-mirk.md` annoté "réalisé, voir mirk-poc-debug".

## Implementation Decisions

### Moteur et versions

- `flutter_map` pinné à **7.0.2**, pas 8.x : parité stricte avec le code validé par le POC. Toutes les nouvelles dépendances strictement pinnées (règle projet).
- Les 6 packages sont ajoutés dans un plan Wave 0 dédié avec audit `DEPENDENCIES.md` + `flutter pub deps` transitives + CI verte, avant tout code.

### Périmètre d'import autorisé (remplace `check_avoid_maplibre_leak`)

- `package:flutter_map` et `package:latlong2` autorisés uniquement dans : `lib/infrastructure/map/**`, `lib/presentation/widgets/fog_layer.dart`, `lib/presentation/widgets/fog_clip_path.dart`, `lib/presentation/screens/map_screen.dart` (composition du widget).
- Interdits partout ailleurs, en particulier `lib/domain/**` (gate `check_domain_purity` existant) et `lib/application/**`.
- Justification : l'invariant FOG-07 impose que `MapCamera.of(context)` soit lu dans le `build()` d'un enfant direct de `FlutterMap`. Le `FogLayer` est donc structurellement un consommateur flutter_map, on l'assume et on le liste explicitement plutôt que de l'abstraire artificiellement.

### Seam `MirkRenderer` et `MirkPaintContext`

- La signature `paint(Canvas, Size, MirkPaintContext)` est conservée : Phase 10 audite ce seam, il doit rester pur (pas de type flutter_map dans le domaine).
- `MirkPaintContext` est étendu **une seule fois** dans cette phase (précédent Plan 09-02) avec les données dérivées de la caméra dont les renderers ont besoin : `pixelOrigin` (x, y) déjà sign-flippé si Android, `zoomScale = pow(2, zoom - referenceZoom)`, `canvasOffset`, et une fonction de projection `LatLng → Offset` exposée sous un type domaine (record ou callback typé), jamais `MapCamera` lui-même.
- Le `FogLayer` construit ce contexte à partir du snapshot `MapCamera` unique, puis délègue au `MirkRenderer` actif via le provider existant. Le `FogLayer` est la frontière ; le renderer ne connaît pas flutter_map.

### Les 4 variants builtin

- Seul `atmospheric` (shader) est validé same-canvas par le POC. Il devient l'implémentation portée de `fog_layer.dart` / `_FogPainter`.
- `solid_fill`, `candlelight`, `heavenly_clouds` doivent rester compilables et sélectionnables (gate `check_mirk_variant_file_count`) et passer par le même `clipPath` disques + même frame Canvas. Pour `heavenly_clouds` (noise animé) appliquer le même mécanisme `pixelOrigin` / `zoomScale`. Aucune régression visuelle ne doit apparaître sur `solid_fill` qui n'a pas de noise à ancrer.
- Si l'adaptation de `candlelight` / `heavenly_clouds` dépasse le budget de la phase, elle est reportée en Phase 13 avec note explicite dans `deferred-items.md`, mais les variants ne sont jamais supprimés.

### Style et assets

- Brancher `assets/maps/style.json` via `ThemeReader` de `vector_tile_renderer`. Si des expressions ne sont pas supportées, adapter le style (via `tool/prepare_style.dart` existant) plutôt que de forker le renderer. Fallback documenté : `ProtomapsThemes.lightV3()` pour `standard` le temps d'ajuster.
- `StyleRewriter` (réécriture des URI PMTiles dans le style pour MapLibre) devient probablement inutile : supprimer si plus aucun appelant, avec ses validators et le gate `check_style_no_external_url` conservé côté asset.
- `assets/maps/glyphs` et `sprites` : supprimer si `vector_tile_renderer` ne les consomme pas, après vérification de l'impact sur le rendu des labels.

### Persistance et perf

- Les disques viennent de `DriftRevealedDiscStore` uniquement. Pas de repo mémoire parallèle.
- Le `SdfCache` (clé quantifiée PERF-08) est porté tel quel. La courbe de coût rebuild avec des volumes de disques persistés plus grands que ceux du POC (caveat #6) est mesurée pendant l'UAT via le logger `infrastructure.mirk.sdf` et notée pour Phase 10.
- Le probe `frame_delta` (PERF-07) et les loggers `fog_transform` / `sdf_rebuild` / `wisp_transform` / `dev_marker` sont portés mais **actifs uniquement en verbose logging** (flag `--dart-define=DEBUG=true` ou toggle du debug menu). En production, seuls erreurs et events métier (règle CLAUDE.md §Logging).

### Constantes

- Renommer les `kPoc*` en convention MirkFall dans `lib/config/constants.dart` : `kMirkFogReferenceZoom = 13.0`, `kMirkFogNoiseTilePx = 384.0`, `kMirkWisp*` (drift 1.5 m/s, cap 200, warm-up 5 s). Les constantes fog déjà présentes dans MirkFall (couleurs, drift, scale, boundary) sont conservées : le POC les a héritées du donor.
- Zooms initial / min / max : **ne pas importer aveuglément** 19 / 10 / 20 du POC. Aligner sur les constantes MirkFall existantes et le comportement session (BUG-003 D avait fixé le zoom par défaut). Le POC ouvrait à 19 pour rendre les wisps lisibles pendant les walks indoor, ce n'est pas une décision produit.
- `kPocFogIntegerWrapPeriodPx` n'existe plus (FOG-18) : si une copie donor traîne dans MirkFall, la supprimer.

### FOG-23 et Android

- Le sign-flip `Platform.isAndroid ? (x, -y) : (x, y)` est une correction permanente d'un écart de codegen GLSL Skia iOS Metal vs Android GLES, pas un workaround temporaire. Porter avec sa docstring de rationale (commit POC `a73a0cc`). Ne jamais le retirer "pour nettoyer".

### Suppressions

- `lib/infrastructure/map/maplibre_map_view.dart`, `lib/presentation/widgets/mirk_overlay.dart`, `lib/infrastructure/mirk/offscreen_fog_renderer.dart` (itération BUG-014), les 3 méthodes `*FogImageSource` de `MapView` et leurs fakes, les 4 tests `mirk_overlay_*_test.dart`, `map_screen_repaint_boundary_test.dart`, `tool/check_avoid_maplibre_leak.dart` (remplacé), les README de `lib/domain/map` / `lib/infrastructure/map` mis à jour.

### Stratégie de tests

- Porter les tests fog / wisp du POC (27 fichiers sous `test/presentation/widgets/fog_*`, `test/infrastructure/mirk/**`, `test/wisp/**`) en renommant le package. `fog_layer_camera_snapshot_test.dart` et `fog_layer_single_camera_snapshot_test.dart` sont les gardes de l'invariant FOG-07.
- Garder la discipline TDD RED / GREEN des plans Phase 09 pour tout code nouveau (adapter, `MirkPaintContext` étendu, `PmtilesSource` chemin absolu).
- CI verte à chaque wave, commits atomiques `feat(09.1-XX):` / `refactor(09.1-XX):` / `test(09.1-XX):` / `chore(09.1-XX):` / `docs(09.1-XX):`.

### Claude's Discretion

- Ordre de suppression des assets glyphs / sprites (peut attendre la fin de phase).

### ABI shader à préserver (PORTBACK §4)

| Slot | Uniform | Source Dart |
|------|---------|-------------|
| 0..1 | `uResolution` | taille du Rect peint |
| 2 | `uTime` | `Stopwatch.elapsedMicroseconds * 1e-6`, Stopwatch tenu **par référence** par le painter (sinon noise figé) |
| 3..4 | `uPixelOrigin` | `camera.pixelOrigin` brut, `.y` négatif sur Android (FOG-23) |
| 5..40 | uniforms donor inchangés | constantes fog MirkFall existantes |
| 41 | `uZoomScale` | `pow(2, camera.zoom - kMirkFogReferenceZoom)` |

Total 42 float slots. Formule shader verrouillée : `worldPx = fragUv * uResolution + uPixelOrigin; noiseUv = worldPx / (kNoiseTilePx * uZoomScale);`. `uSdfRect` reste l'identité `(0, 0, 1, 1)`.

### Les 10 invariants (PORTBACK §5), en une ligne chacun

1. Un seul `MapCamera.of(context)` par build du `FogLayer`, snapshot passé au painter.
2. Un seul `canvas.getTransform()` par paint.
3. `canvas.translate(-canvasOffset)` symétrique en tête de paint.
4. Rotation désactivée tant que FOG-16 (b) n'est pas fait.
5. `Stopwatch` pour le calcul, `DateTime.now()` uniquement pour le tag `epochSecond` des rollups.
6. Rollups loggers alignés 1 Hz sur `epochSecond` pour la corrélation inter-flux.
7. Noise échantillonné en coordonnées monde (formule ci-dessus).
8. Identité visuelle bit-identique au zoom de référence 13.0 (`uZoomScale = 1.0`).
9. `uSdfRect` identité.
10. `uTime` via Stopwatch par référence.

### Réserves héritées à garder en tête (VERDICT §caveats)

Rotation off (UX-02) ; stockage disques à brancher sur Drift (#3) ; style MirkFall à rebrancher (#4) ; perf validée iPhone d'abord (#5, #8) ; coût rebuild SDF à re-mesurer avec plus de disques (#6) ; walks POC faits indoor au WalkSimulator, prévoir une vraie marche GPS (#7) ; FOG-23 permanent (#9) ; disposition Impeller non vérifiée sur Adreno 6xx (#10).

### Pièges du POC à ne pas refaire (shader-fix-retrospective §Pitfalls)

- Ne pas modifier l'identité visuelle du shader pour masquer un bug de tracking.
- Ne pas mélanger pixels écran et distance monde (wisps 18 px/s = la faute d'origine).
- Ne pas "interdire toute modif du shader" : le fix final a eu besoin d'un uniform de plus.
- Diagnostiquer avec un split contrôlé (spiral debug) plutôt qu'à l'œil sur 6 walks.
